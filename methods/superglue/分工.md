### 指标选择

1. 匹配充分性：**初始匹配点数量** **+** **RANSAC 后内点数量** --> **内点率**（内点数 / 初始匹配数）

2. 匹配准确性：**重投影误差 + 角点误差** 
3. 配准有效性：**配准成功率**
4. ~~复杂场景鲁棒性：低纹理场景（白墙、桌面、天花板、地板）+ 重复纹理场景（瓷砖、窗格、走廊、书架）~~

4. 计算效率：**单对图像处理时间**

### 指标定义

1. 初始匹配点数：**进入RANSAC之前的最终候选匹配对数量**

2. 内点数：cv2.findHomography(..., method=cv2.RANSAC, ransacReprojThreshold=3.0, maxIters=2000, confidence=0.90) **内点数 = RANSAC 返回 mask 中为 1 的匹配对数量**

3. 内点率：**内点数 / 初始匹配点数**

4. 重投影误差：对估计得到的单应矩阵 H，将图像 A 中的匹配点投影到图像 B，计算与对应真实匹配点之间的欧氏距离，单位为像素。

   median reprojection error + mean reprojection error

   **只对内点计算，主报 median，辅报 mean。**

5. 配准成功率：一对图像被判为配准成功，当且仅当同时满足：

   1. 成功估计出单应矩阵 H
   2. `2 >= N_min`
   3. `median reprojection error <= τ`

   **HPatches**

   `N_min = 10`

   `τ = 3 px`

   **InLoc**

   `N_min = 15`

   `τ = 5 px`

   最终 = 成功配准的图像对数 / 总图像对数

6. 单对耗时：从输入两张已加载并完成统一resize的图像开始，到输出最终单应矩阵H和inlier mask结束的总时间

   报平均单对耗时！也就是**全部跑完 / 图像对数**

### 统一实验规范

#### 1. 图像 resize 到多少

统一规则：保持长宽比，长边缩放到 640。
如果原图长边本来就小于 640，不放大。
缩放后再把宽高向下取整到 8 的倍数。

```
示例
- 1600×1200 → 640×480
- 1024×768 → 640×480
- 500×375 → 保持 500×368（368 向下取到 8 的倍数）
```

#### 2. 彩色还是灰度

全部方法都用灰度图做实验。

#### 3. 每个方法是否限制最大匹配点数

送进 RANSAC 的最终候选匹配对，最多保留 1000 对

**规定**

- 如果某方法最后候选匹配数 > 1000
   就按“该方法自己的置信度/匹配质量”排序，取前 1000
- 如果 < 1000，就全保留

**各方法排序方式**

- **ORB / SIFT**：按匹配距离从好到坏排序
- **SuperGlue / LoFTR**：按匹配置信度从高到低排序

#### 4. 置信度阈值怎么设

**SuperPoint + SuperGlue**

- 用官方默认思路
- match_threshold = 0.20
- 如果输出太多，再按置信度排序取前 1000

#### 5. RANSAC 参数固定成什么

```python
cv2.findHomography(
    ptsA, ptsB,
    method=cv2.RANSAC,
    ransacReprojThreshold=3.0,
    maxIters=2000,
    confidence=0.995
)
```

**额外规定**

- 内点数 = mask 中值为 1 的点数
- 内点率 = 内点数 / 初始匹配点数
- 如果匹配点数 < 4，直接记为：
  - H估计失败
  - 内点数 = 0
  - 内点率 = 0
  - 重投影误差 = NaN
  - 配准失败

#### 6. 单对耗时是否包含模型加载

不包含模型加载。

**统一定义**

单对耗时 = 从“两张图已经读入内存并完成 resize + 灰度化”开始到输出最终 H 和 inlier mask 为止

#### 7. 是否 warm-up

**具体规定**

- **SuperGlue**：正式计时前先 warm-up 5 对图像

**正式统计耗时时**

- 不算 warm-up 那几对
- 只统计正式测试集平均单对耗时
